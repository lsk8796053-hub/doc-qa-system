参考答案

生成器是一种特殊的迭代器，使用 yield 关键字返回值。与返回整个列表的普通函数不同，生成器每次产生一个值，并在产生值后暂停执行，保留其状态。

这使得生成器在处理大数据集时非常节省内存，因为它们一次只把一个元素加载到内存中。所有的生成器都是迭代器，但不是所有的迭代器都是生成器。

Key Point

Generator = 特殊 Iterator + yield + 惰性求值 + 状态保留

参考答案

REST (Representational State Transfer) 是一种软件架构风格。RESTful API 的主要原则包括：

🔒 无状态性

每个请求必须包含所有必要信息，服务器不存储客户端状态

🔗 统一接口

使用标准 HTTP 方法：GET, POST, PUT, DELETE

📱 客户端-服务器分离

职责分离，提高可移植性和可扩展性

💾 可缓存性

响应需标记为可缓存或不可缓存

MLOps 生命周期：

数据收集 模型训练 模型部署 监控重训练

与 DevOps 的区别：

1

DevOps 关注代码版本控制；MLOps 还需管理数据版本和模型版本

2

模型存在概念漂移/数据漂移，需要持续监控

3

MLOps 需要 CT (Continuous Training)，自动触发重训练
